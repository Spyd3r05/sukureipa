## KMPDC Scraper

This is a web scraper that scrapes the KMPDC website for licensed medical practitioners.

### Installation

```bash
npm install puppeteer
```

### Usage

```bash
node index.js
```

### Output

The output will be a JSON file containing the scraped data.
